# Wordcraft: Mohammed-Moniem component repository

This repository contains the complete modified Wordcraft engine source for **Mohammed-Moniem/wordcraft**. It is an in-progress integration component. Original upstream references, MIT/Apache licences, NOTICE, third-party notices and attribution remain in the tree.

The current source adds bounded successful XML parsing per package read and cumulative chart corrections for retained-group axis resolution, explicit axis scale/format authority, percent combinations and stock Open/Close ordering. A boolean simplification and test formatting are maintenance changes. The float/note test correction changes its page-height premise by one point; it does not claim a production layout repair. See [current source and CLI evidence](verification/current-word-progress.md) and the preserved [XML-budget evidence](verification/word-xml-budget.md).

A separately prepared current artifact is an unsigned debug **macOS ARM64 command-line component**, with complete source, native and legal-reference archives and adjacent SHA-256 files. It is not a native GUI application or complete offline compiler kit. The verification document identifies the exact build and synthetic local DOCX/chart observations, including the preserved failed drivers and their separate read-only semantic reconciliation. Preparation and local checks do not establish public-download execution.

Use the current CLI's `--help` and `commands --json` for supported commands. Imported advanced combination/stock charts in the synthetic checks are display/preserve objects; they do not become editable chart models. The independently created stacked-column chart exercises the supported edit commands.

[OFFLINE.md](OFFLINE.md) retains the earlier source4 download and integration instructions. Those existing source4 and XML-only releases remain historical versions; their binaries do not contain every current source change. The original engine README is [UPSTREAM-README.md](UPSTREAM-README.md), and [SOURCE-PROVENANCE.json](SOURCE-PROVENANCE.json) preserves the original source inventory and README mapping.

Current evidence does not qualify browser/WASM runtime, Windows 11, Intel macOS, private-host integration, arbitrary hostile-document security, real Office rendering, general document fidelity or Microsoft/Adobe feature parity. This is not an official upstream release.
