# Wordcraft: Mohammed-Moniem component repository

This independent repository contains the complete modified wordcraft engine from the preserved embedded-office-suite source4 progress baseline. Publication destination: **Mohammed-Moniem/wordcraft**. Upstream references remain for attribution and dependency provenance.

This is an in-progress integration component, not a completed Microsoft/Adobe replacement. The first independently reviewed source adaptation adds a per-Package successful XML parse-element budget; see [validation and limits](verification/word-xml-budget.md). See [OFFLINE.md](OFFLINE.md) for your GitHub-hosted native/WASM runtimes, Rust tools, vendors, support assets and Node/WebView integration.

The original engine README is [UPSTREAM-README.md](UPSTREAM-README.md). Original MIT/Apache licences, NOTICE and third-party notices remain in this tree. This is not an official upstream release.

Source suite commit: 7e5cd4793c4f3f7c193cffbd1cf2c44ea81a9816. [SOURCE-PROVENANCE.json](SOURCE-PROVENANCE.json) records every original source file/hash/mode, including the README rename.

Current evidence covers selected source4 workflows on macOS ARM64/Intel and Windows Server2022; Windows11, the private harness, full optional-feature coverage and product/file fidelity remain unverified. New repository publication does not establish a new build or runtime qualification.

The `v0.1.0-source4-baseline` tag and its assets preserve the original baseline. New source in `main` is a progress update; baseline runtime downloads do not contain this new change.
